# DevJobs

Projeto desenvolvido na disciplina de Linguagem de Programação para Internet.

O objetivo da atividade foi praticar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript.

## Funcionalidades

- Exibição de vagas de tecnologia
- Busca e filtro de vagas
- Layout responsivo
- Tema claro e escuro
- Armazenamento da preferência de tema no navegador

## Conteúdos utilizados

- HTML semântico
- CSS
- Flexbox
- CSS Grid
- Media Queries
- JavaScript
- DOM
- Eventos
- Arrays
- localStorage

## Como executar

Abra o arquivo `index.html` em um navegador.
